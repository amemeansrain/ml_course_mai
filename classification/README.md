# Лабораторная работа №2 — Классификация

Готовая работа: `titanic_classification.ipynb`. CSV находится в `data/`.

Для Python 3.9–3.12 установите зависимости и откройте ноутбук из этой папки:

```bash
python -m pip install -r requirements.txt
python -m notebook titanic_classification.ipynb
```

Выберите Python установленного окружения и выполните **Restart Kernel and Run All Cells**.
